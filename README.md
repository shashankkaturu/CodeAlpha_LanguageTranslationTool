# 🌐 AI Translation Tool

A simple web-based AI Translation Tool developed as part of the **CodeAlpha Internship Project**.

The application allows users to enter text, select a source language and target language, and translate the text into the selected language.

---

## 🚀 Features

- 🌍 Translate text between multiple languages
- 📝 Simple and user-friendly interface
- 🔄 Source and target language selection
- 📋 Copy translated text
- 📱 Responsive design
- ⚡ Fast translation using Google Translate service
- 🔤 Supports Indian languages

---

## 🗣️ Supported Languages

The application currently supports:

- 🇬🇧 English
- 🇮🇳 Telugu
- 🇮🇳 Hindi
- 🇮🇳 Tamil
- 🇮🇳 Kannada
- 🇮🇳 Malayalam
